# Tableau Economic Dashboard (2025–2026)

## Overview
This Tableau dashboard analyzes macroeconomic indicators including inflation, unemployment, GDP growth, and interest rates.

## Features
- Dual-axis visualization (Inflation vs Unemployment)
- Time-series analysis
- Reference lines and bands
- Annotated insights highlighting economic trends

## Key Insights
- Inverse relationship between inflation and unemployment
- GDP growth shows steady decline over time
- Interest rates peaked early before declining

## Tools Used
- Tableau Public
- Data Visualization
- R (data preprocessing)
